On-Premises vs Cloud:
--------------------- 
On-Premises means the company owns and manages everything in its own data center. 

Ex:
A bank maintaining its own servers in its own building. 

Responsibilities:
The company Manages:
. Physical Servers
. Networking
. Storage
. OS
. Security
. Backup
. Updates
. Application

Cloud:
The cloud provider manages physical infra, and the customer uses services through the internet

Ex: 
Creating a VM in Azure instead of buying a physical server

Important Cloud Terms:
=======================
Scalability:

Scalability means increasing or decreasing resources based on demand.

2 Types of Scaling:

Vertical Scaling	-> Scaling up/down
Horizontal Scaling	-> Scaling out/in

1. Vertical Scaling: 
- adding more power to an existing server.
- ex: increasing CPU, RAM or Storage.
- Simple but has hardware limits


2. Horizontal Scaling:
- adding more servers or removing servers.
- ex: running multiple web servers behind a load balancer
- more flexible and commonly used in cloud platforms.


High Availability:
High Availability means keeping the application running with minimum downtime.

Ex: If one server fails, another server continues running the application.

Fault Tolerance:
Fault Tolerance means the system continues working even if one component fails.

Ex: Application running in multiple data centers (Availability Zones)

Disaster Recovery:
Disaster Recovery means restoring applications and data after a major failure

Ex: If One region goes down, application can be restored in another region.

Pay-as-you-go:
Pay only for the resources you use.

Ex: If you run a VM for 5 Hours, you pay only for those 5 hours.
