Access Tiers:
==================
In cloud, cost optimization is not only about deleting unused resources.
It is also about placing data in the correct tier Based on how frequently it is accessed.

Azure Blob Storage provides 4 major access tiers.

Hot Tier        -> frequently accessed data. 
Cool Tier       -> infrequently accessed data that sill needs to be available immediately.
Cold Tier       -> for rarely accessed data where storage cost should be lower, but the data should still remain online
Archive Tier    -> is for data that is alomost never accessed but must be retained for compliance or long-term backp. Archive is the lowest storage cost, but retrival takes time because the data must be rehydrated before use.

            Cost for Storage        Access for the Data.

Hot Tier        Higher              Lower                   30>
Cool Tier       High                Low                     60>
Cold Tier       Low                 Higher                  100>
Archive         lowest              Highest                 



Redundancy:
Azure stores multiple copies of your data so that yout data remains durable and available during failures.

Multiple Redundancy Options

Single Region
    LRS - Locally Redundant Storage   99.999999999% (11 nines)
    ZRS - Zone Redundant Storage       99.9999999999% (12 9s)

Multi Region
    GRS  - Geo Redundant Storage         99.99999999999999% (16 9s)
    GZRS - Geo Zone Redundant Storage    99.99999999999999% (16 9s)
