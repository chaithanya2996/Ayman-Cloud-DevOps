Hypervisor

2 Types of Hypervisor:

1. Type-1 Hypervisor (Bare Metal Hypervisor)
2. Type-2 Hypervisor (Hosted Hypervisor)

Type-1 Hypervisor:
- Runs directly on the physical hardware.
Examples:
-----------------
VMware ESXi
Microsoft Hyper-V
KVM
Xen

Advantages:
-----------------------
High performance
Strong security
Common in enterprise data centers


Type-2 Hypervisor:
Runs on top of an existing operating system.

Examples:
------------------------
Oracle VM VirtualBox
VMware Workstation

Advantages:
-------------------------
Easy to install
Ideal for learning, testing, and development
