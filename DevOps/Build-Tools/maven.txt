Maven is a build tool
Purpose: Build

Build Automation tool
Project Management tool

maven will download and install necessary dependencies
Maven = POM.xml -> Project Object Model

POM consists of -> dependencies, plugins, configurations, project details

.java = Basic raw code
Compile = .class  = executable files
.jar = group of .class files [Works for Backend]

.war = FE + BE
        html,css,js
        Java


Build LifeCycles
Build Phases
Maven Goals

Validate
Compile : .class [target]
Test
Package: war
Install: /root/.m2
Deploy
Clean
