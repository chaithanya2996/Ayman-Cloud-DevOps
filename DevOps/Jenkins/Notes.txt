JENKINS IS A CI/CD tool

REALITY: JENKINS IS ONLY FOR CI

CI : CONTINOUOS INTEGRATION = CONTINOUOS BUILD + CONTINOUOS TEST (OLD CODE WITH NEW CODE)


DAY-1: 100 LINES : BUILD + TEST
DAY-2: OLD LINES 100 + NEW LINES 100 = 200 LINES : BUILD + TEST
DAY-3: OLD LINES 200 + NEW LINES 100 = 300 LINES : BUILD + TEST
