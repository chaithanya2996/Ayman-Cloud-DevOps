What is Azure Portal?
=====================
Azure Portal is a Web-based interface where users can manage Azure Services.

URL:

https://portal.azure.com

What we can do in Azure Portal

- Create resources
- delete resources
- start/stop vms
- create storage accounts
- create virtual networks
- manage users and access
- view billing and cost
- open cloud shell
- monitor resources
- create app services
- connect azure devops with azure services.


Azure Resource Hierarchy:
==========================

Azure follow a hierarchy.

Microsoft explains Azure management scope in four major levels: management groups, subscriptions, resource groups and resources.


Tenant
Subscription
Resource Group
Resources.


What is Tenant?
===============
Example ->  
Apartment		Azure
Flats -> Unique ID	Tenant ID
subscription -> payment details (billing) -> Subscriptions
organization -> Rooms	-> groups
things -> 		-> our resources, vm, stroages, databases, 

A tenant represents an organization in Microsoft Entra ID.

Earlier, Microsoft Entra ID was called Azure Active Directory.


Simple Explanation:
Tenant is like the main identity boundary for an organization.


Ex:
ABC Technologies, it may have one Microsoft Entra Tenant.

Inside that tenant, user, groups, applications and subscriptions can exist.


What is Subscription?
=====================
A subscription is used for billing, access control, and resource management.


All Azure resources are created inside a subscription.

Simple Terms:
Subscription is like a billing account or container where azure services are created.

Free Trail Subscription  
Pau-As-You-Go Subscription
Company Subscription
Azure for Students Subscription 

- One Azure Account can have one or more subscriptions.
- Billing is connected to subscription
- Access can be controlled at subscription level
- Resource Groups are created inside a subscription


What is Resource Group?
============================
A resource group is a logical container used to group related Azure Resources.

RG is like a Folder for Azure Resources.

RG-AzureDevOps-Training
	- VM
	- VNET
	- Storage Account
	- App Service
	- SQL Database


Why Resource Group is Important,
- Easy to manage resources, to delete all lab resources together, easy to track cost, 
to apply access control, to organize project-wise resources.

Ex: a company-project

RG-Ecommerce-Dev
RG-Ecommerce-Test
RG-Ecommerce-Prod

What is Resource?
======================
A Resource is an actual Azure Service created inside a Resource Group.

Ex of Azure Resources
VM, Stroage accounts, Vent, publicip, nsg, app services, sql database, key vault, container registry

RG is the container/folder
Resource is the actual service. File inside the folder.


Tenant vs Subscription vs Resource group vs Resource
