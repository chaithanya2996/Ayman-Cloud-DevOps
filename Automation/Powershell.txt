A PowerShell command is called a cmdlet (pronounced command-let).

Most cmdlets follow this naming convention:

Verb-Noun
For example:

Get-Process
Verb = Get
Noun = Process

This means Get the running processes.

1. Cmdlet Syntax

General syntax

Verb-Noun -Parameter Value

Example

Get-Service -Name Spooler

Breakdown

Part	Meaning
Get-Service	Cmdlet
-Name	Parameter
Spooler	Value

2. Verbs

PowerShell uses standard verbs.

Verb	    Meaning	        Example
Get	        Retrieve	    Get-Process
Set	        Modify	        Set-Location
New	        Create	        New-Item
Remove	    Delete	        Remove-Item
Start	    Start something	Start-Service
Stop	    Stop something  Stop-Process
Restart	    Restart	        Restart-Service
Test	    Check	        Test-Path

Example
Get-Date

Returns the current date and time.

3. Parameters:
Parameters provide additional information to a cmdlet.

Example

Get-Process -Name chrome

Here

Get-Process → cmdlet
-Name → parameter
chrome → parameter value

Multiple parameters

Get-ChildItem -Path C:\Users -Recurse

Meaning

Search inside C:\Users
Include all subfolders
